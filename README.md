# p

Llista mestra i scripts d'un pack privat. Sense suport.

- `modpack.json`: quins fitxers, quina versio, empremta SHA-1, d'on surten i a quin costat van.
- `config/`, `root/`: fitxers que entren al zip.
- `scripts/build_pack.py`: munta el zip a `dist/`.
- `scripts/release_pack.py`: publica el zip com a Release i imprimeix l'enllaç directe.
- `CHANGELOG.md`: una linia per canvi.

Els jars no es guarden aqui.
